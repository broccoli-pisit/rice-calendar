# ปฏิทินล้นเกวียน — PWA วางแผนปลูกข้าว

เว็บแอปแบบติดตั้งได้ (PWA) ใช้ออฟไลน์ได้ ข้อมูลแปลงเก็บไว้ในเครื่อง (localStorage)

## ฟีเจอร์
- หลายแปลง: ชื่อ, พื้นที่ (ไร่), วิธีปลูก, กลุ่มพันธุ์, วันปลูก, บันทึก — บันทึกอัตโนมัติ
- วงล้อหมุนได้ / slider / ปฏิทิน / คำนวณย้อนจากวันเกี่ยว
- ตารางงาน (ปุ๋ย น้ำ เก็บเกี่ยว) เป็นวันที่จริง + งานใน 14 วันข้างหน้า รวมทุกแปลง
- ปริมาณปุ๋ยรวมตามพื้นที่ (กก. / กระสอบ)
- รายงานรายแปลง / ทุกแปลง → พิมพ์หรือบันทึกเป็น PDF (A4)
- ตั้งค่าช่วงความเสี่ยง (เขียว/เหลือง/แดง) เอง, สำรอง/นำเข้าข้อมูล .json

## Deploy บน GitHub Pages
```bash
cd rice-app
git init && git add . && git commit -m "rice calendar PWA"
gh repo create rice-calendar --public --source=. --push
gh api -X POST repos/{owner}/rice-calendar/pages -f "source[branch]=main" -f "source[path]=/"
```
เปิดที่ `https://<username>.github.io/rice-calendar/` แล้ว
- Android (Chrome): เมนู ⋮ → "ติดตั้งแอป" / "เพิ่มลงในหน้าจอหลัก"
- iPhone (Safari): ปุ่มแชร์ → "เพิ่มลงในหน้าจอโฮม"

ทดสอบในเครื่อง: `python3 -m http.server 8000` แล้วเปิด http://localhost:8000

## แก้ข้อมูล
- โปรแกรมน้ำ/ปุ๋ยของแต่ละกลุ่มพันธุ์: `data.js` → `PROGRAMS`
- ช่วงความเสี่ยงค่าเริ่มต้น: `data.js` → `DEFAULT_ZONES` (หรือแก้ในหน้าตั้งค่าของแอป)
- เมื่อแก้ไฟล์แล้ว เปลี่ยน `CACHE` ใน `sw.js` (เช่น `rice-cal-v2`) เพื่อบังคับอัปเดต
